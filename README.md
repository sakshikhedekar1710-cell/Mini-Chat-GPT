🤖 Mini ChatGPT Clone
This project is a full-stack chatbot web application built using Django, Django REST Framework, React, and Tailwind CSS.

It was my first project after learning Django, and it gave me hands-on experience building a complete application from scratch — connecting a modern frontend with a scalable backend, integrating APIs, and managing chat sessions.

The app allows users to interact with a chatbot while maintaining a smooth, session-based conversation flow.

Initially, the chatbot responses were powered by the OpenAI API. However, since it requires a paid subscription, I later replaced it with a simple echo bot for demonstration and testing.

Working on this project helped me understand backend architecture, REST API integration, authentication workflows, and real-world debugging. Exploring these concepts and solving practical challenges made the learning process both challenging and enjoyable.
